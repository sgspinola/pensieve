# Security Policy

## Supported versions

Only the latest commit on `main` (what is deployed) receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately via GitHub's
[private vulnerability reporting](https://github.com/sgspinola/pensieve/security/advisories/new)
— do not open a public issue.

Include what you found, steps to reproduce, and the impact you expect. You can
expect an initial response within a week. Once a fix is released, the advisory
will be published with credit to the reporter, unless you prefer otherwise.
